## Candidate and review gates

An initial integrated Bun 1.4.2 check passed 552 tests with 6,430 assertions. Subsequent review follow-ups receive a final full check and exact CLI runtime validation before publication; their results will be recorded here. The final installer diagnostics fixture passed on authenticated Bun 1.3.11 (9 tests, 28 assertions). It exercises real Bun failures using malformed installer input, avoiding network retry timing. Local validation uses a frozen installation of dependencies, without a node_modules symlink.

Local Codex inspection and independent Claude review identified and corrected the issues above. CodeRabbit availability and per-PR findings are recorded in the PRs; unavailable or rate-limited reviews are not approvals. The release checklist governs exact main/tag identity, publication and independent consumer acceptance.

The CLI prepared with signed Bun 1.3.11 is 7,875,605 bytes, SHA256 `2a1d899ec55c7741f78e27ffe384cc9f212a107606c6d02b7dc99bc76effd64a`. That exact CLI produced deterministic compiled images on linux/amd64 and linux/arm64. Both ran with default UID 65532 (no user override), read declared assets, and passed signed compiler/runtime and base-revision checks under a read-only filesystem, dropped capabilities and no network.
