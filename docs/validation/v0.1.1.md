# 0.1.1 validation

This release integrates reviewed PRs #79–#86, including follow-up corrections for protected report replacement, quoted/expanded credential redaction, numeric root users and strict undeclared-import guidance. The integration preserves all PR head commits and resolves overlapping configuration, closure and documentation changes.

## Candidate and review gates

The final integrated check passed on signed Bun 1.3.11: `bun run check` completed 553 tests with 6,428 assertions and no failures, including TypeScript checking. Dependencies were installed with `bun install --frozen-lockfile --ignore-scripts` without a node_modules symlink. The real installer failure fixture uses malformed package JSON for deterministic pre-network failures in both build and production modes; unit cases cover credential-bearing registry diagnostics.

[Integration PR #87](https://github.com/sakajunquality/bunko/pull/87) passed all 20 CI checks in [run 34352510841](https://github.com/sakajunquality/bunko/actions/runs/34352510841). It preserved the final heads of #80–#86, which GitHub marked merged; #79 was merged separately. The resulting main commit is `d060057d7831da8dff65bc762abbbffab4ee3879`, whose [main CI 34353120124](https://github.com/sakajunquality/bunko/actions/runs/34353120124) also passed. The matrix covers Linux/macOS and Bun 1.3.11, 1.3.12, 1.3.13, 1.4.0 and 1.4.2, with integration, runtime injection, telemetry and application fixtures.

[Manual candidate run 34353144615](https://github.com/sakajunquality/bunko/actions/runs/34353144615) prepared and verified artifacts at that exact main commit without publication. Its downloaded CLI matches the local candidate byte for byte.

Local Codex inspection and independent Claude review identified and corrected the issues above. CodeRabbit follow-up reviews were rate-limited and the GitHub Codex review request had not returned a result before merge; neither is counted as an approval. Per-PR review findings and local/Claude results are recorded in the PRs. The release checklist governs exact main/tag identity, publication and independent consumer acceptance.

The CLI prepared with signed Bun 1.3.11 is 7,875,605 bytes, SHA256 `2a1d899ec55c7741f78e27ffe384cc9f212a107606c6d02b7dc99bc76effd64a`. That exact CLI produced deterministic compiled images on linux/amd64 and linux/arm64. Both ran with default UID 65532 (no user override), read declared assets, and passed signed compiler/runtime and base-revision checks under a read-only filesystem, dropped capabilities and no network.
