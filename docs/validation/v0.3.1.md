# v0.3.1 validation

This release includes explicit source assets overriding `.gitignore`, opt-in native CA trust, and the development guide from #113 and #114. Publication and independent acceptance evidence will be completed before defaults are promoted.

Preparation uses Bun 1.3.13. The native CA smoke accepts `BUNKO_CLI` so the exact prepared distribution can package a gitignored Go executable and verify TLS on Linux amd64 and arm64, including an untrusted negative case. Runtime containers use nonroot users, read-only filesystems, dropped capabilities and no external networking.

External application-machine acceptance and live private ECR/Artifact Registry immutability behavior remain unverified. This release does not certify additional providers or native ABIs.
