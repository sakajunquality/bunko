# v0.8.0 validation

This release adds safe image rebasing through [PR #163](https://github.com/sakajunquality/bunko/pull/163), merged as `8672b034601165db19d398476f83e3bdc262dd97`. Its final [CI run](https://github.com/sakajunquality/bunko/actions/runs/34743321766) passed all 29 checks, including native amd64/arm64 execution of glibc/musl images in bundle/source/compile modes.

CodeRabbit findings were independently checked and corrected, including loader-path lookup, semantic volume comparison and ELF header validation. The final ELF-header finding was [confirmed addressed](https://github.com/sakajunquality/bunko/pull/163#discussion_r3998970619). Claude Fable was unavailable due to usage credits and is not counted as a completed review. CodeRabbit was requested on the release-only PR but rate limited; that version/documentation diff received local review, without claiming external approval.

## Exact release candidate

Frozen installation and release preparation used Bun 1.3.13. The CLI is 8,000,338 bytes with SHA256 `ececf296bd9ae202d1ce4dfc54e8c1255313a0983e70a9e618dd9e05cd58d7e7`. Typecheck and 864 tests / 8,264 assertions passed with two platform-specific skips and no failures. The exact bundled candidate passed all 12 glibc/musl × amd64/arm64 × bundle/source/compile runtime cases, including unchanged generated layer digests, removed application source, nonroot/read-only execution and private CA HTTPS trust.

A separate real local Distribution registry and cosign 3.1.3 verified four new signed subjects. These are controlled base-extension fixtures, not certification of arbitrary OS-library updates. Dedicated rebase partial-publication fault injection and live hosted-registry transitions remain additional validation work. ELF header checks do not prove transitive ABI or symbol compatibility; filesystem changes require the documented operator contract.
