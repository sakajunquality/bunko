# v0.8.0 validation

This release adds safe image rebasing through [PR #163](https://github.com/sakajunquality/bunko/pull/163), merged as `8672b034601165db19d398476f83e3bdc262dd97`. The final [feature CI run](https://github.com/sakajunquality/bunko/actions/runs/34743321766) passed all 29 checks, including native amd64/arm64 execution of glibc/musl images in bundle/source/compile modes. Local Bun 1.3.13 checks passed 864 tests and 8,264 assertions with two platform-specific skips and no failures.

The exact feature bundle passed all 12 runtime cases with unchanged generated layer digests, deleted application source, nonroot/read-only operation and private CA HTTPS trust. A real local Distribution registry and cosign 3.1.3 verified four new signed subjects. These are controlled base-extension fixtures, not certification of arbitrary OS-library updates. Dedicated rebase partial-publication fault injection and live hosted-registry transitions remain additional validation work.

CodeRabbit findings were independently checked and corrected. Its final ELF-header finding was [confirmed addressed](https://github.com/sakajunquality/bunko/pull/163#discussion_r3998970619). Claude Fable was unavailable due to usage credits and is not counted as a completed review.

## Release preparation

Version 0.8.0 is being prepared from the merged feature. Frozen installation and release preparation used Bun 1.3.13. The candidate CLI is 8,000,338 bytes with SHA256 `ececf296bd9ae202d1ce4dfc54e8c1255313a0983e70a9e618dd9e05cd58d7e7`; its version command returned 0.8.0. Candidate hashes, signed main/tag workflow identities, published container digest and independent npm consumer results will be recorded after each verification completes. Publication is not claimed by this preparation record.

The setup-bunko Marketplace Action v0.1.0 retains CLI v0.6.2 by default; its independent promotion remains separate. Existing immutable versions are preserved for rollback.
