# v0.6.1 validation

This patch includes [#149](https://github.com/sakajunquality/bunko/pull/149): plaintext credential warnings and token-service trust documentation. Warnings are deduplicated per CLI invocation, including when multiple projects create separate registry clients. Bun support remains >=1.3.13 <1.5.

Prepared with Bun 1.3.13: CLI 7,951,474 bytes, SHA256 `f1e29337d7b711e70c6f32e3f69519783b6522ee044c14dcbad25caac9ee053b`. Frozen installation, typecheck and all 814 tests / 7,976 assertions passed. The isolated bundled CLI and exact-candidate application and signed runtime-injection fixtures passed on Linux amd64 and arm64.

The two-project CLI regression reproduced duplicate warnings before the fix and passes afterward. Two consecutive invocations each publish both images and report one warning without credential values. All 70 registry/resolve tests and typecheck passed with Bun 1.3.13; the new regression also passed with Bun 1.4.2. Claude reviewed the follow-up and release with no actionable findings. CodeRabbit reviewed the original change; subsequent reviews were rate limited, which is not approval.
