# v0.6.1 validation

This patch includes [#149](https://github.com/sakajunquality/bunko/pull/149): plaintext credential warnings and token-service trust documentation. Warnings are deduplicated per CLI invocation, including when multiple projects create separate registry clients. Bun support remains >=1.3.13 <1.5.

The multi-project CLI regression reproduced two warnings before the fix and one after it. Two consecutive invocations each publish both images and report one warning without credential values. All 70 registry/resolve tests and typecheck passed with Bun 1.3.13; the new regression also passed with Bun 1.4.2. Claude reviewed the follow-up with no actionable findings. CodeRabbit reviewed the original change; its follow-up was rate limited, which is not approval.

Release preparation, candidate identities, workflow runs and independent consumer evidence will be recorded here as they complete. GitHub, npm and GHCR publication are pending; examples remain pinned to the previously verified release until acceptance succeeds.

Private provider policies and external application-machine acceptance are not certified by this patch's automated tests. Historical evidence does not certify this release.
