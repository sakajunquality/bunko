# v0.12.0 release validation

Release preparation is in progress. Publication and consumer availability are not yet claimed.

This release contains #241–#251: shared runtime preparation and cancellation, reduced workspace copying, persisted-format compatibility diagnostics, OS-backed cache locking and staging, stable packing identities and conservative retention, Babel parser migration, TypeScript 7 and dependency updates.

The parser size/scan tradeoff and Babel 7 maintenance deadline are recorded in [PARSER.md](../PARSER.md). Cache migration and rollback constraints are recorded in [CACHE_RETENTION.md](../CACHE_RETENTION.md) and [FORMAT_COMPATIBILITY.md](../FORMAT_COMPATIBILITY.md). Host Bun support remains unchanged.

The release candidate is prepared with the release workflow's Bun 1.3.13. Exact artifact identity, runtime results, workflow/source identities and public-channel evidence will be recorded after verification. The independently versioned setup-bunko Marketplace Action is not released as part of this CLI publication; its published v0.1.1 default remains CLI v0.8.0 and examples will explicitly select this CLI release.
