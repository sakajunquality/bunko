# 0.2.0 validation

[PR #106](https://github.com/sakajunquality/bunko/pull/106) raises the host/toolchain minimum to Bun 1.3.13 and removes retired verified runtime pins. Final head `19fe1594961eae7e1f2bd60ba486b100ba828be4` passed [CI 34439977896](https://github.com/sakajunquality/bunko/actions/runs/34439977896) and npm preparation. It merged as `6b67d9adb95e77c8bfe646811b4f79a62eef8102`. Codex and Claude reviewed the implementation; the Claude follow-up found no actionable correctness blockers. CodeRabbit's README scope finding was fixed and confirmed resolved.

The local full suite passed 653 tests with 7,061 assertions on Bun 1.3.13. After review corrections, typecheck and 20 focused tests (154 assertions) passed. Actual Bun 1.3.11 and 1.3.12 processes reject both source and bundled CLIs with upgrade/pinning guidance; 1.3.13 executes version 0.2.0. Historical npm metadata tests cover 0.1.0-rc.5, 0.1.4, 0.2.0-rc.1 and 0.2.0.

The candidate was prepared with Bun 1.3.13 (`bf2e2cecf`). Its CLI is 7,906,124 bytes, SHA256 `b78dbb3e6cf0351626c035696d188a036ff17d8f94d094f81cd82ec73ac6f6f0`. Bundled CLI smoke, signed runtime injection and deterministic compilation passed on linux/amd64 and linux/arm64. Runtime checks include official revision, static-base rejection, local OCI input, cache reuse and the native-library boundary. Registry push/pull, native dependencies, layer reuse and Docker archive/load passed with both the existing fixture base and the updated 1.3.13 base `oven/bun@sha256:7e8ed3961db1cdedf17d516dda87948cfedbd294f53bf16462e5b57ed3fff0f1`.

Main protection now requires integration and the six Linux/macOS test contexts for Bun 1.3.13, 1.4.0 and 1.4.2. Other rules, conditions, enforcement and bypass actors were verified unchanged. Published 0.1.4 remains immutable and available to older Bun users.

External application-machine acceptance and private ECR remain unverified. Cache backend expansion, musl/rebase and setup Action separation are outside this release.
