# v0.8.2 validation

This release includes security changes #172–#175 and consolidates Dependabot updates #177–#184. TypeScript 7 (#176) is deferred because its package removes JavaScript compiler APIs used at runtime; migration is tracked in #185. TypeScript 6 remains eligible for separate validation.

The Action major upgrades use Node 24 on GitHub-hosted runners. The workflows use no removed Buildx inputs or deprecated build-push environment variables. setup-node continues to use explicit Node 24 with package-manager caching disabled and npm OIDC publication.

## Candidate and publication

Validation and publication are in progress. No new artifact or provider acceptance is claimed until the exact candidate and published bytes are verified. The separate setup-bunko v0.1.1 Action retains CLI v0.8.0 by default; its next promotion is deferred.
