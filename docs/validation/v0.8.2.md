# v0.8.2 validation

This release includes security changes #172–#175 and consolidates Dependabot updates #177–#184. TypeScript 7 (#176) is deferred because its package removes JavaScript compiler APIs used at runtime; migration is tracked in #185. TypeScript 6 remains eligible for separate validation.

The Action major upgrades use Node 24 on GitHub-hosted runners. The workflows use no removed Buildx inputs or deprecated build-push environment variables. setup-node continues to use explicit Node 24 with package-manager caching disabled and npm OIDC publication.

## Exact candidate

Prepared with Bun 1.3.13, frozen dependencies, and install scripts disabled. The CLI is 8,002,320 bytes, SHA256 `73d29766acede035226230cb646e70eeacb79b3a4452a5f5a3ada65747646c5d`.

That exact CLI passed eight completed-image structure/behavior scenarios on Linux amd64 and arm64, compiled-image determinism and runtime asset reads, and font rendering in bundle/source modes using both fontconfig and explicit directory discovery. Missing font configuration, missing lazy dependencies, and empty data negative controls failed as expected. Local amd64 runs use emulation; CI image acceptance uses native runners.

CodeRabbit reviewed the dependency/release diff and identified a stale README release link, which was corrected. The dependency lockfile changes were reviewed locally; CodeRabbit excludes lockfiles.

## Publication

Validation and publication are in progress. No new artifact or provider acceptance is claimed until the exact candidate and published bytes are verified. The separate setup-bunko v0.1.1 Action retains CLI v0.8.0 by default; its next promotion is deferred.
