# 0.1.0 validation

The candidate JavaScript CLI was prepared with Bun 1.3.11. Its size is 7,863,753 bytes and SHA256 is `c9839f9e0756ae43ba921d754cdd429f85824ee8e5329847342f6fd0ddee4d08`. The stable version promotes rc.5 application build behavior and adds the previously reviewed npm packaging workflow; it does not introduce new application build features.

Candidate checks, publication and published-consumer acceptance are separate gates. The [rc.5 validation](rc5.md) and [initial npm publication](npm-rc5.md) remain historical evidence for their exact versions. The release PR and tag CI repeat the supported Bun matrix. The CLI release, official container and npm package are published independently; this record will be updated with their exact source identities and verification results after publication.

The private GHCR application conformance run remains blocked by account billing. Private ECR and the external application-machine matrix remain unverified; stable versioning does not change those limits. musl and rebase are tracked separately in issues #53 and #54.

## Candidate results

The full local check passed 523 tests with 6,225 assertions. The exact candidate CLI above passed deterministic compilation and application execution on Linux amd64 and arm64 using host Bun 1.4.2, including verification of the authenticated compiler and base Bun revision. `packages/` has no changes relative to rc.5.

The npm post-publication consumer allows 21 attempts with 15-second delays and bounded individual fetch time, inside a 15-minute job. This follows the several-minute initial metadata propagation delay observed for rc.5; it does not retry or replace a published version.
