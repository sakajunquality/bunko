# v0.9.0 validation

Release scope: SBOM build evidence (#192), rebase operations (#193), Node runtime (#195), keyless signing (#194), and registry credentials (#196, #197, #199). Native AWS credentials (#198) are excluded pending live AWS acceptance. Existing Docker-compatible AWS helpers remain supported.

## Exact candidate and checks

Prepared with Bun 1.3.13, frozen dependencies and installation scripts disabled. The CLI is 8,090,584 bytes, SHA256 `9617ddfaaeae3324c84897f175975f1362eb59b97f020d26c403205d6c021a39`. Typecheck and 948 tests passed, with two platform-specific skips, zero failures and 8,725 assertions. Final-head PR CI and merged-main CI/security checks passed.

These exact CLI bytes passed eight Node 24 scenarios (glibc/musl, bundle/source, amd64/arm64), twelve rebase scenarios (glibc/musl, bundle/source/compile, amd64/arm64), and compile determinism with runtime asset reads on both architectures. Runtime checks use nonroot containers with read-only filesystems; local amd64 execution uses emulation and is distinct from native CI. Rebase tests retain generated layers and exercise runtime/private-CA trust boundaries. These fixtures do not certify arbitrary applications or runtime upgrades.

## Review and registry acceptance

Claude Fable review was independently assessed. Its Docker Hub helper-key observation was checked against Docker CLI and fixed. CodeRabbit findings were resolved: repository-scoped Podman helpers fail before resolution, explicit normalized credential matches reject ambiguity, and failed configuration commits after a helper update report that completed operation explicitly. Local configuration writes serialize cooperating bunko writers; external Docker/Podman concurrent writes are only detected best-effort, and the final compare/rename window is documented rather than represented as atomic compare-and-swap.

The final AWS-free main commit passed [GHCR acceptance run 35076186549](https://github.com/sakajunquality/bunko/actions/runs/35076186549), including native token publication/pull, private-key signing/verification and a nonroot read-only CLI container. Artifact Registry environment-token acceptance and remaining limits are recorded in [registry credential validation](registry-credentials.md). GKE/Cloud Build metadata identity and AWS workload identity are not certified by token/emulator checks. Native AWS is not present in the release CLI.
