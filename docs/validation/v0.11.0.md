Independent Codex reviews started without the implementation conversation. Two findings were fixed and independently rechecked: Git clean/process filters, including sibling submodules, executing during metadata collection; and upload EOF starting a read-header deadline before socket transmission completed. A real-HTTP fixture was isolated from Bun's retained proxy state after a reproducible test-order failure; the corrected full suite passed. CodeRabbit availability varied and rate-limited/pending status was not counted as approval. The release-preparation PR also received a separate zero-context Codex review with no substantive findings.

The first public-base acceptance attempt correctly rejected unrelated ambient repository-scoped Docker credentials. Fixtures were rerun with an isolated anonymous configuration and passed. Existing user credentials were not changed. Local cross-architecture Docker execution uses emulation where needed; native CI is separate evidence.

The npm registry returned 404/ETARGET after accepting publication. Read-only propagation checks were retried; publication was not repeated. The original publication workflow and independent consumers passed after visibility returned.

Existing AWS acceptance is historical: this release does not newly certify EKS Pod Identity, EC2 IMDSv2 or ECR Public. Runtime memory sharing, automatic cache recovery, cache identity/retention redesign, TypeScript compiler migration and historical format interoperability remain open under #185, #220, #223, #229 and #231. Seventeen completed audit issues were closed.

The separate setup-bunko development default was updated to CLI v0.10.0 in its PR #3. Its published v0.1.1 Action remains immutable and defaults to CLI v0.8.0; examples select CLI v0.11.0 explicitly. An independent Marketplace Action release is deferred.
