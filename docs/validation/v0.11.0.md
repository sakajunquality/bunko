# v0.11.0 release validation

Preparation is in progress. This document does not claim that GitHub, npm or GHCR publication has completed. Current published defaults remain on v0.10.0 until independent artifact acceptance.

The release contains #203–#210 and #232–#238: host support narrowing, credential/input hardening, portable Node runtime handling, rebase acceptance, keyless tokens, bounded SBOM evidence, compile execution options, deadline/cancellation fixes and cache diagnostics.

Independent Codex reviews started without the implementation conversation. Two findings were fixed and independently rechecked: Git clean/process filters (including sibling submodules) executing during metadata collection, and upload EOF starting a read-header deadline before socket transmission completed. The final combined implementation passed type checking and 1,011 tests (2 skipped, 0 failed; 8,990 assertions). Final merged main source before the version bump is `80663deb00d4303fb172dd0e512f71efaea65f0e`.
