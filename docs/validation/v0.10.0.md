# v0.10.0 release validation

Status: preparation; publication has not yet occurred.

Scope: native AWS credentials and private ECR upload compatibility from #198, plus the fixed-candidate OIDC acceptance workflow from #201. Bun support is unchanged for this release; CI/support reductions are a subsequent change.

[GitHub OIDC acceptance](https://github.com/sakajunquality/bunko/actions/runs/35157819828) passed environment and native Web Identity paths against a dedicated private ECR repository. See [AWS validation](aws-registry-credentials.md) for exact scope and remaining provider limits.

The release preparation toolchain is Bun 1.3.13. Publication identities, artifact hashes, consumer checks and promotion evidence will be added after the corresponding steps pass. The independent setup-bunko Action remains v0.1.1 with CLI v0.8.0 as its default.
