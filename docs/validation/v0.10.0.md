The npm registry initially returned ETARGET after accepting publication. Read-only propagation checks and consumer verification were retried; publication was not repeated. The publish workflow's verification eventually passed.

[GitHub OIDC acceptance](https://github.com/sakajunquality/bunko/actions/runs/35157819828) passed environment and native Web Identity paths against a dedicated private ECR repository. See [AWS validation](aws-registry-credentials.md). Deployed EKS IRSA/Pod Identity, EC2 IMDSv2 and ECR Public remain unverified. Local cross-architecture container execution uses emulation where needed and is distinct from native CI coverage.

CodeRabbit reviewed the implementation in #198; its stale authentication overview finding was corrected. The release-preparation PR was rate limited, so no additional bot approval is claimed. The independent setup-bunko Action remains v0.1.1 with CLI v0.8.0 as its default; examples explicitly select v0.10.0. Its independent release is deferred.
