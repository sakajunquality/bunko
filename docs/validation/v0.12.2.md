All listed workflows succeeded. Runs without an explicit attempt above completed on attempt 1. Independent Codex reviews of the merged implementation and release preparation found no actionable findings; CodeRabbit completed the preparation review without actionable comments.

Main CI initially failed the Node 24/amd64 rebase smoke Docker preflight's 10-second deadline. Only that failed job was retried on the same source and passed; no product change was made for the runner timeout. Additional local Node acceptance passed all 8 cases. npm publication attempts 1 and 2 failed in preparation when different GitHub release asset downloads returned HTTP 500; neither attempt ran `publish`. Retrying the failed preparation and its dependent jobs on the same source succeeded on attempt 3. npm publication executed once, followed by normal registry propagation and successful published-consumer verification. No tag, version or artifact was replaced.

Local cross-architecture Docker tests use emulation where needed; native CI is separate evidence. Candidate fixtures used an isolated empty Docker credential configuration for public bases. Native variant pairing has focused synthetic ELF-metadata unit coverage for sharp-style names; the executed native fixtures use other addons and do not constitute a new real-sharp application acceptance claim. Redaction covers recognized credential-shaped strings and build scratch paths, not every possible application secret. This release does not newly certify cloud providers or private workloads.

Host Bun requirements and persisted formats are unchanged. The separately versioned setup-bunko Action is not promoted by this CLI release: immutable v0.2.0 retains default CLI v0.12.0. Updated examples explicitly select v0.12.2; `version: latest` also selects the current published stable CLI.
