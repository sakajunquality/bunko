# v0.6.2 validation

This patch addresses #152 and #153 through PRs #155 and #156. Image asset caches support cross-device staging. Static native dependency advisories distinguish paired inactive libc variants without removing binaries or hiding unpaired/ambiguous cases. Bun support remains >=1.3.13 <1.5.

Linux /tmp versus /dev/shm regressions covered file/directory extraction, warm reuse and failed-commit cleanup. A read-only /dev/shm check confirmed unsupported test environments skip cleanly. CodeRabbit identified the mount-availability test issue, which was fixed; later reviews were rate limited. Claude reviewed both implementations with no remaining actionable findings.

Real @napi-rs/canvas 1.0.5 and @resvg/resvg-js 2.6.2 workloads rendered PNGs on slim for amd64/arm64 without missing-library advisories. Distroless retained the two genuine GNU libgcc_s.so.1 findings per architecture and failed at runtime for that missing library. See [native addon evidence](native-libc-variants.md).

Prepared with Bun 1.3.13: CLI 7,953,322 bytes, SHA256 `0c2418a2d107ff4c49cfb7abe49b2136689477788400ff7950d1eee0ffcc165e`. Frozen installation, typecheck and 818 tests / 8,012 assertions passed; the two Linux-only cross-device cases were skipped on macOS and passed separately in Linux. The isolated bundled CLI, application fixtures and signed runtime-injection fixtures passed on Linux amd64 and arm64. The exact candidate also passed a complete CLI build with a cross-device asset cache, including warm reuse, and repeated both native rendering/expected-failure checks on both architectures.
