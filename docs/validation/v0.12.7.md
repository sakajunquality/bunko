The Docker-based smoke runners, including the glibc/musl × architecture runtime fixtures, were not run locally for this record because no Docker daemon was available; CI on the release PR and main is the evidence for them. Host Bun support and persisted formats remain unchanged. The OCI audit's hardlink identity, runnable artifactType classification, optional document mediaType and nested manifest idle-timeout findings remain open.

CodeRabbit raised two findings on PR #301: examples pairing CLI v0.12.6 with Bun 1.4.5 would fail in compile mode and runtime injection, because v0.12.6 has no 1.4.5 runtime pin. Both were fixed before merge by keeping Bun 1.4.4 in those examples until this promotion. No other external review was requested. The independently versioned setup-bunko v0.2.0 retains default CLI v0.12.0 and `bun-version` 1.4.2; updated examples explicitly select v0.12.7 and Bun 1.4.5.
