# v0.7.0 validation

This release adds verified musl/Alpine runtime support through [PR #160](https://github.com/sakajunquality/bunko/pull/160). Its final [CI run](https://github.com/sakajunquality/bunko/actions/runs/34583231539) passed, including Bun 1.3.13, 1.4.0, 1.4.1 and 1.4.2 on native amd64/arm64 runners. Each musl job executed bundle/source/compile images, native xxhash where supported, private-CA HTTPS, warm cache identity and invalid-base rejection.

Claude and CodeRabbit findings were independently checked and corrected. Additional user-posted review nits extended signed-fixture coverage to all 16 runtime pins, moved native libc rejection before assembly and removed duplicate full executable reads. Cache limits and UTF-8 replay consistency have regression coverage.

Publication and exact release-candidate acceptance are pending. Feature CI is not a substitute for release artifact verification. The setup-bunko Marketplace Action v0.1.0 retains CLI v0.6.2 by default; its independent promotion is deferred. Private provider policies and external application-machine acceptance have not been repeated for this release.
