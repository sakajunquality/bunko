# v0.3.0 validation

This release adds hardened cache exports and a common registry/local backend API. It retains stable Bun >=1.3.13 <1.5 support. The published 0.2.0 release remains available for rollback.

## Implementation evidence

- Registry hardening: PR #109; required CI passed, full implementation review found no remaining blockers, and Distribution 3 fallback/promotion/restore checks passed.
- Typed backends: PR #110; 675 tests and 7,169 assertions passed on the 0.3.0 candidate after final review fixes. Focused regression checks cover warm managed-cache preservation, implicit registry reads, disabled writes, strict failure causes, local restore identity, ordered mixed imports, multiple exports, path guards and offline behavior.
- The bundled CLI exported and restored a portable local cache with identical image digest. Distribution 3 verified typed registry/local exports and a fresh local restore.
- Final complete-source Claude review found no remaining correctness blockers. CodeRabbit identified two actionable issues; both were fixed and acknowledged as resolved, including rejection of symlinked cache roots and exact ordered Action argument assertions. Final feature CI passed in run `34444505149` on `e12effdb57b1ff2fe54a16628cd9868f9a81d723`.

## Release acceptance

GitHub asset, npm and GHCR acceptance passed independently. The distribution defaults in this change use those verified artifacts. This document does not certify live private-provider immutability/cleanup policies or external application-machine workloads.
