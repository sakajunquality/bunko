# v0.8.3 validation

This release updates the bundled TypeScript compiler API from 5.9.3 to 6.0.3 in #187 and includes the npm/pnpm prebuilt application example from #189. TypeScript 7 migration remains tracked in #185. Supported Bun versions and runtime/rebase boundaries are unchanged.

## Exact candidate

Prepared with Bun 1.3.13, frozen dependencies and install scripts disabled. The CLI is 8,032,605 bytes, SHA256 `8c9741c46aa01c2ed0e7e3b540ff05e104fa43261d7fea9ddb797d17fea39b15`. Compared with v0.8.2, it grows by 30,285 bytes (0.38%). Typecheck and 879 tests passed, with two platform-specific skips, no failures and 8,353 assertions.

The exact CLI passed eight completed-image structure/behavior scenarios, compiled-image determinism and runtime asset reads on Linux amd64 and arm64. Missing data and dependency negative controls failed as expected. Local amd64 runs use emulation; CI image acceptance uses native runners.

Both npm and pnpm prebuilt-example paths passed deterministic packaging and HTTP health/static asset execution on both architectures with a nonroot user, read-only root filesystem, dropped capabilities and no external network. Host tools were Node 25.9.0, npm 11.12.1 and pnpm 10.1.0. Outputs differ in esbuild module labels because npm and pnpm use different install paths; cross-package-manager byte identity is not claimed.

## Parser comparison and review

A common corpus of 219 executable JavaScript files (16,406,942 bytes) was scanned with both parsers using Bun 1.3.13 on macOS arm64. In a repeated five-run comparison, median full-corpus read/parse time was 1,151 ms with TypeScript 5.9.3 and 1,206 ms with 6.0.3; parsing the TypeScript implementation alone took 498 ms versus 554 ms. These local measurements are workload-specific, not a performance guarantee. Declaration files containing newer syntax were excluded from the common corpus because the old parser cannot parse them.

The code and lockfile diff received local review. CodeRabbit was explicitly requested but rate limited, so no external approval is claimed for the release PR. Final PR CI and security checks passed.
