The release PR reproduced the macOS cancellation failure and captured its cause: `process.kill(-pid, 0)` reported `EPERM` while checking a cancelled group after SIGKILL. Previously this escaped cleanup and replaced exit 143 with exit 1. The fix keeps denied groups pending until a probe confirms `ESRCH`; persistent denial reaches the existing deadline and retains scratch. Denial is never treated as proof of exit. Two deterministic regressions fail against the old implementation and pass after the fix on Bun 1.3.13 and 1.4.2. All eight cancellation tests pass on both versions. Updated candidate and final CI validation are pending.
