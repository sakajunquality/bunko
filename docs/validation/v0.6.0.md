Frozen dependency installation, typecheck and all 810 tests / 7,958 assertions passed. Application checks covered migrations, workers, database access, HTTP/native modules/assets and shutdown; runtime checks covered signed release/revision verification, static-base rejection, local bases, runtime cache and native library boundaries.

## Cancellation regression

Release validation captured a macOS race: a process-group exit probe returned `EPERM` after SIGKILL, escaping cleanup and replacing exit 143 with exit 1. The fix retains denied groups until `ESRCH` confirms exit; persistent denial reaches the existing deadline and retains scratch. Two deterministic regressions fail against the previous implementation and pass after the fix on Bun 1.3.13 and 1.4.2. All eight cancellation tests and the final macOS CI matrix passed. The assertion now includes subprocess stderr to make failures diagnosable.
