# ko workflow coverage

The current feature comparison and remaining boundaries are maintained in [COMPARISON.md](COMPARISON.md). Bunko supports source builds, workspace targets, deployment resolution, local Docker/kind workflows, explicit apply, conventional assets, label selectors and immutable reference files. These workflows follow ko conventions while retaining Bun-specific configuration and supported-platform limits.

Historical runtime evidence for the portable workflow additions remains in [validation/ko-runtime.json](validation/ko-runtime.json). It does not imply full CLI, Go compiler-cache, platform or debugger compatibility.
